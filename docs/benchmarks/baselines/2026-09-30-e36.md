# September 30 E36 reference: E35 with the INT8 shared lm_head

**Status: current performance reference, promoted by the owner.** E36 is the operational
default measured as it serves: [E35](2026-09-30-e35.md) plus the INT8 W8A16 `lm_head` that the
target shares with the DFlash2 drafter, packed once at load. Its runtime identity is
[`2026-09-30-e36-lm-head`](../../operational-identities/2026-09-30-e36-lm-head.json), which
`scripts/check-f0.py` verifies by default. The frozen E31 record remains the engine identity.

## Measurement

- **Suites.** Two complete native Rigmark suites on the E36 serving load (n = 2,
  108 requests), from the [E36 experiment](../experiments/2026-09-30-e36-lm-head.md).
- **Protocol.** Upstream Rigmark `c5a0db0` with the reference flags (every default plus
  `reasoning_effort` low), no cache salt, a fresh comparison ID per suite, direct LAN HTTP to
  the rank-0 API.
- **Fidelity.** Against the BF16 head, dense perplexity +0.018% [+0.013, +0.024] and top-1
  agreement 99.6% (424 windows on one measurement load).
- **Integrity.** 108/108 requests completed with visible responses, 36/36 exact prefill token
  counts, 30/30 decode output gates, zero validation, protocol or runtime errors. The memory
  guard never triggered; rank 0's lowest MemAvailable was 3.86 GiB.

## Limits

- Two suites on one load; C1/C2/C4 differences within about 7% are noise, and the E35
  comparison crosses loads.
- Target logits change slightly; see the fidelity result above.
