# E03 C5 15 GiB functional smoke

**Recorded outcome:** the functional smoke passed and the owner retained the C5
operational configuration. The performance outcome is unresolved; this is not a
performance promotion or a new baseline.

The live recipe was the accepted E03 system identity with only `MAX_NUM_SEQS` changed
from six to five. It retained the 15 GiB KV pool per rank, 262,144-token request limit,
E03 replay connector, mHC sources and draft-budget scheduler. The engine reported
1,344,328 KV tokens, a theoretical 5.13 full-context windows; that allocation ratio
does not establish five-request full-context concurrency.

`/health` returned 200, both post-boot functional gates passed 32.505 seconds after
health, the private four-rank operational identity passed, and autostart selected the
same C5 overlay. That private identity was derived from the frozen E03 system identity
by changing the maximum sequence count only. It is not a performance record, and the
frozen E03 baseline bytes remain unchanged.

Rigmark ran once with the frozen E03 source, prompts, seed and comparison ID, using
`--runs 1 --decode-tokens 8192 --skip-prefill --skip-concurrency`. All three requests
produced visible responses and DONE markers, ended with `stop`, and passed their native
completion gates. Rigmark exited zero and the receipt contains no error entries.

| Workload | Requests | Prompt / completion tokens | Finish | Gate | Decode tok/s | TTFT (s) |
| --- | ---: | ---: | --- | ---: | ---: | ---: |
| Code | 1 | 132 / 1,885 | stop | 1/1 | 54.220 | 0.437863 |
| Prose | 1 | 124 / 1,001 | stop | 1/1 | 31.831 | 0.383717 |
| Structured | 1 | 110 / 436 | stop | 1/1 | 69.507 | 0.454660 |

Each rate and TTFT is one sample. No prefill, concurrency, repeated suite,
maximum-context occupancy or isolated performance comparison was run, so these values
cannot support a throughput claim or reproduce the accepted E03 performance reference.
The single code TTFT, 0.437863 seconds, is above the frozen E03 median of 0.396 seconds
and its 0.362744–0.406898-second first-request range. One observation cannot establish
parity or a regression.
